# Sign Language Recognition

A collaborative machine learning project completed through the **National Student Data Corps (NSDC) at UCLA** in 2024. I served as the **project lead**.

## Project overview

This project explored image classification for recognizing static American Sign Language (ASL) alphabet gestures. The project materials include a written report and the Sign Language MNIST dataset used for the analysis.

## Dataset

**Sign Language MNIST** contains 28 × 28 grayscale images of hand gestures for 24 static ASL letters. The letters J and Z are excluded because they require motion.

- Training set: **27,455** images
- Test set: **7,172** images
- Format: CSV, with one `label` column and 784 pixel-value columns
- [Original dataset on Kaggle](https://www.kaggle.com/datasets/datamunge/sign-language-mnist)

The CSVs are linked to their original source rather than duplicated in this repository because of their size.
